## [1.0.0] - 2026-07-28

### 🎉 Initial Release

This marks the first stable release of **OpsBoard**, a production-inspired cloud-native DevOps platform demonstrating Infrastructure as Code, GitOps, Kubernetes orchestration, CI/CD automation, and observability.

---

### ✨ Added

#### Infrastructure

- AWS infrastructure provisioning using Terraform
- Amazon EKS cluster deployment
- IAM configuration
- Networking components
- Infrastructure as Code (IaC)

#### Containerization

- Dockerized frontend and backend applications
- PostgreSQL container support
- Docker Compose for local development

#### Kubernetes

- Kubernetes manifests
- Helm chart for application deployment
- Namespace organization
- Service definitions

#### CI/CD

- GitHub Actions workflow
- Automated Docker image builds
- Amazon ECR integration
- Deployment automation

#### GitOps

- Argo CD configuration
- Declarative deployments
- Automatic synchronization
- Self-healing deployment model

#### Monitoring
